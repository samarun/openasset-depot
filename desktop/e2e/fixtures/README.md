# Review Runtime Fixtures

`animated-cube.glb` and `animated-cube.fbx` are tiny animated cube scenes
created by the OpenAsset Depot project in Blender. `simple-triangle.gltf` is a
hand-authored embedded-buffer glTF scene. They exist only for decoder and WebGL
regression testing and contain no third-party artwork, textures, brands, or
production data.

The fixtures are distributed under the repository's Apache-2.0 license.
